# 📊 Naive Bayes Classification Project

This project demonstrates the implementation of the **Naive Bayes algorithm** for classification tasks using Python and Scikit-learn. It covers the complete machine learning workflow including data preprocessing, model training, prediction, and evaluation.

## 📌 Project Overview

* Algorithm: **Naive Bayes**
* Type: Supervised Machine Learning (Classification)
* Objective: Predict target classes based on input features using probabilistic learning
